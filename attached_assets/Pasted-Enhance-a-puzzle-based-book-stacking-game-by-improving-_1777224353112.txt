Enhance a puzzle-based book-stacking game by improving interaction, visuals, audio, and overall player experience to make it more immersive, cozy, and addictive.

🕹️ Core Interaction Improvements
Allow two placement styles:
Drag & Drop: Player can click, hold, and drag a book to a desired position.
Click-to-Place: Player selects a book and then clicks a valid shelf area to place it.
Provide real-time placement preview (ghost outline showing if placement is valid or not).
Add soft snapping to guide books into valid positions smoothly.
Include subtle haptic-like feedback (visual/animation) when grabbing or placing a book.
❌ Game Over Logic
The game should automatically end when:
No remaining space can accommodate any of the available books.
Before ending:
Optionally highlight possible placements briefly (if none → game over).
Show a clear “No Moves Left” state with smooth transition.
